About TrainSight

TrainSight adalah aplikasi web prediksi yang dirancang untuk memperkirakan durasi pelatihan model Machine Learning berdasarkan ukuran dataset menggunakan algoritma Regresi Linear Sederhana.

Aplikasi ini menggunakan model yang benar-benar dilatih menggunakan dataset nyata dari Kaggle, dibangun dengan Flask (backend) dan Scikit-learn (machine learning), serta antarmuka yang modern dan responsif.

Research Background

Penelitian ini bertujuan menganalisis hubungan antara ukuran dataset pelatihan (dalam MB) dan waktu yang dibutuhkan untuk melatih model Machine Learning (dalam menit).

Semakin besar ukuran dataset, umumnya semakin lama waktu yang diperlukan untuk training. Hubungan ini dapat dimodelkan secara matematis menggunakan Regresi Linear, yang memungkinkan prediksi waktu training sebelum proses pelatihan dimulai.

"Analisis Pengaruh Ukuran Dataset terhadap Waktu Pelatihan Model Machine Learning Menggunakan Regresi Linear"

Machine Learning Method

Regresi Linear Sederhana adalah metode statistik yang memodelkan hubungan antara satu variabel independen (X) dan satu variabel dependen (Y).

Persamaan Regresi Linear: Y = a + bX
Y = Training Time (minutes) X = Dataset Size (MB) a = Intercept (titik potong sumbu Y) b = Koefisien (kemiringan garis)

Parameter a dan b diperoleh dari proses training menggunakan metode Ordinary Least Squares (OLS) yang meminimalkan jumlah kuadrat residual.

Model Limitations

Perlu dipahami bahwa durasi pelatihan model Machine Learning dipengaruhi oleh banyak faktor, antara lain:

  • Jenis algoritma ML yang digunakan
  • Spesifikasi CPU/GPU perangkat
  • Jumlah epoch pelatihan
  • Kompleksitas arsitektur model
  • Konfigurasi hyperparameter
  • Ketersediaan memori (RAM/VRAM)
Hasil aplikasi ini merupakan estimasi berdasarkan pola dataset, bukan jaminan durasi training pada semua perangkat dan konfigurasi.
