About TrainSight

Apa itu TrainSight?

TrainSight adalah aplikasi web prediksi yang menggunakan model Regresi Linear Sederhana untuk memperkirakan durasi pelatihan model Machine Learning berdasarkan ukuran dataset.

Aplikasi ini merupakan implementasi nyata dari riset akademik "Analisis Pengaruh Ukuran Dataset terhadap Waktu Pelatihan Model Machine Learning Menggunakan Regresi Linear".

Regresi Linear Sederhana

Simple Linear Regression

Regresi Linear adalah metode statistik untuk memodelkan hubungan linear antara variabel independen (X) dan variabel dependen (Y).

Persamaan Model: Y = a + bX
Y = Waktu Training (menit) X = Ukuran Dataset (MB) a = Intercept b = Koefisien

Estimasi waktu training membantu merencanakan resource komputasi dan mengoptimalkan pipeline ML secara keseluruhan.
